## 遇到的问题和解决方案

### 1. 依赖版本冲突
- **问题**：Pinia 3.0.4 需要 Vue 3.5.11 或更高版本，但项目使用的是 Vue 3.4.21
- **解决方案**：使用 `npm install --legacy-peer-deps` 命令安装依赖

### 2. 文档读取问题
- **问题**：任务书和开题报告的 docx 文件无法正常读取
