
# 第五章 系统测试

## 5.1 测试环境

测试环境包括硬件环境和软件环境两部分。

硬件环境方面，测试服务器使用一台配置为 Intel Core i7-10700K 处理器、16GB 内存、512GB SSD 硬盘的计算机。测试客户端使用多种设备，包括 iPhone 13、华为 Mate 40 Pro、小米 12 等智能手机，以及 Windows 10 和 macOS 操作系统的电脑。

软件环境方面，后端服务器运行 Node.js 18.x 版本，使用 Express.js 4.x 框架，数据库使用 MySQL 8.0 版本。前端使用 uni-app 框架，支持 H5 和微信小程序两种运行模式。测试工具包括 Postman 用于 API 接口测试，以及 uni-app 自带的开发者工具用于前端调试。

测试数据方面，系统初始化了多个测试用户、物品、订单和消息数据，用于模拟真实的使用场景。测试用户包括普通用户和管理员用户，测试物品涵盖学习用品、生活用品、电子产品等多个类别。

## 5.2 功能测试

### 5.2.1 用户管理功能测试

用户注册功能测试验证用户能否成功注册账号。测试用例包括正常注册、重复用户名注册、密码强度不足、手机号格式错误等场景。测试结果显示，系统能够正确验证用户输入，拒绝无效注册请求，成功创建有效用户账号。

用户登录功能测试验证用户能否使用正确的账号密码登录系统。测试用例包括正常登录、用户名不存在、密码错误、token 过期等场景。测试结果显示，系统能够正确验证用户身份，生成有效的登录 token，并在 token 过期后要求重新登录。

个人信息管理功能测试验证用户能否修改个人信息。测试用例包括修改头像、昵称、学校、专业等信息。测试结果显示，系统能够正确保存用户修改的信息，并更新数据库中的记录。

### 5.2.2 物品管理功能测试

物品发布功能测试验证用户能否成功发布物品。测试用例包括正常发布、缺少必填字段、图片格式错误等场景。测试结果显示，系统能够正确验证物品信息，拒绝无效发布请求，成功创建物品记录并上传图片。

物品搜索功能测试验证用户能否通过关键词、分类、价格等条件搜索物品。测试用例包括按关键词搜索、按分类筛选、按价格范围筛选等场景。测试结果显示，系统能够正确返回符合条件的物品列表，搜索结果准确。

物品详情功能测试验证用户能否查看物品的详细信息。测试用例包括查看存在的物品、查看不存在的物品等场景。测试结果显示，系统能够正确展示物品详情，对不存在的物品返回错误提示。

### 5.2.3 订单管理功能测试

订单创建功能测试验证用户能否成功创建租赁订单。测试用例包括正常创建订单、选择无效租赁时间、物品已被租赁等场景。测试结果显示，系统能够正确计算租金和押金，生成唯一的订单编号，拒绝无效的订单创建请求。

订单状态流转测试验证订单状态能否正确变更。测试用例包括确认订单、取消订单、完成订单等场景。测试结果显示，系统能够正确处理订单状态的变更，更新相关的订单记录和物品状态。

订单提醒功能测试验证系统能否在订单到期前发送提醒消息。测试用例包括设置订单到期时间，验证系统是否按时发送提醒。测试结果显示，系统能够定时检查订单状态，在订单即将到期时发送提醒消息给用户。

### 5.2.4 消息通讯功能测试

消息发送功能测试验证用户能否成功发送消息。测试用例包括发送文本消息、发送图片消息、发送消息给不存在的用户等场景。测试结果显示，系统能够正确保存消息记录，发送消息给指定用户。

消息接收功能测试验证用户能否接收其他用户发送的消息。测试用例包括接收文本消息、接收图片消息、查看未读消息等场景。测试结果显示，系统能够正确展示消息列表，标记未读消息，更新消息状态。

### 5.2.5 纠纷处理功能测试

纠纷申请功能测试验证用户能否提交纠纷申请。测试用例包括正常提交纠纷、提交已解决的订单纠纷、缺少证据材料等场景。测试结果显示，系统能够正确创建纠纷记录，通知被申请人，拒绝无效的纠纷申请。

纠纷处理功能测试验证管理员能否处理纠纷。测试用例包括查看纠纷列表、查看纠纷详情、给出仲裁结果等场景。测试结果显示，系统能够正确展示纠纷信息，记录仲裁结果，更新相关用户的诚信分。

## 5.3 非功能测试

### 5.3.1 性能测试

性能测试主要包括响应时间测试和并发用户测试。

响应时间测试使用 Postman 模拟用户请求，测量各个接口的响应时间。测试结果显示，大部分接口的响应时间在 100ms 以内，物品列表查询等复杂查询接口的响应时间在 200ms 以内，满足系统的性能要求。

并发用户测试使用 JMeter 模拟多个用户同时访问系统，测量系统在高并发情况下的性能表现。测试结果显示，系统在 100 并发用户的情况下能够正常运行，响应时间保持在可接受范围内，没有出现明显的性能下降。

### 5.3.2 安全性测试

安全性测试主要包括密码加密测试、SQL 注入测试和权限验证测试。

密码加密测试验证用户密码是否正确加密存储。测试结果显示，系统使用 bcrypt 算法对密码进行加密，数据库中存储的是加密后的密码，无法直接获取原始密码。

SQL 注入测试验证系统是否能够防止 SQL 注入攻击。测试用例包括在搜索框、登录表单等输入框中输入恶意 SQL 语句。测试结果显示，系统能够正确过滤恶意输入，防止 SQL 注入攻击。

权限验证测试验证系统是否能够正确验证用户权限。测试用例包括普通用户尝试访问管理员接口、未登录用户尝试访问需要认证的接口等场景。测试结果显示，系统能够正确拦截未授权的请求，返回相应的错误提示。

### 5.3.3 兼容性测试

兼容性测试主要包括设备兼容性测试和浏览器兼容性测试。

设备兼容性测试验证系统在不同设备上的显示效果和功能可用性。测试结果显示，系统在 iPhone、华为、小米等不同品牌的手机上都能够正常显示和使用，界面布局自适应不同屏幕尺寸。

浏览器兼容性测试验证系统在不同浏览器上的显示效果和功能可用性。测试结果显示，系统在 Chrome、Firefox、Safari、Edge 等主流浏览器上都能够正常运行，没有出现明显的兼容性问题。

### 5.3.4 可用性测试

可用性测试通过邀请用户进行实际使用，收集用户反馈。测试结果显示，用户对系统的界面设计和操作流程整体评价较好，认为系统操作简单、界面友好。用户提出的改进意见主要集中在搜索功能的优化和页面加载速度的提升上。

## 5.4 测试结论

经过全面的测试，校园闲置物品共享平台的各项功能均能够正常工作，满足设计要求。

功能测试结果显示，用户管理、物品管理、订单管理、消息通讯和纠纷处理等核心功能模块都能够正确实现，各项操作都能够按照预期执行。

非功能测试结果显示，系统的性能表现良好，响应时间在可接受范围内，能够支持较高的并发用户访问。安全性方面，系统采取了多种安全措施，能够有效防止常见的安全攻击。兼容性方面，系统能够在不同设备和浏览器上正常运行。可用性方面，用户对系统的整体评价较好。

在测试过程中，也发现了一些需要改进的地方，如搜索功能的准确性可以进一步提升，页面加载速度可以优化等。这些问题将在后续的版本迭代中进行改进。

总体而言，校园闲置物品共享平台已经达到了设计目标，可以投入实际使用。
