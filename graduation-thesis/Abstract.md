
# 摘要

随着高校学生人数的不断增长，校园内闲置物品的数量也随之增加。这些物品往往具有一定的使用价值，但由于缺乏有效的流通渠道，常常被闲置甚至丢弃，造成了资源的浪费。本课题旨在设计并实现一个校园闲置物品共享平台，为在校学生提供一个安全、便捷的物品租赁和交易服务。

该平台采用前后端分离的架构设计，后端基于 Node.js 和 Express.js 框架，使用 MySQL 数据库存储数据；前端采用 uni-app 框架，支持多端发布，包括 H5 和微信小程序。平台主要功能包括用户管理、物品发布与浏览、订单管理、消息通讯以及纠纷处理等模块。系统创新性地引入了诚信分机制和纠纷处理流程，保障了交易双方的权益，提升了平台的可信度。

经过测试验证，该平台能够稳定运行，各项功能均能正常工作，满足校园闲置物品共享的实际需求。

**关键词**：校园共享；闲置物品；租赁平台；uni-app；Node.js

# Abstract

With the continuous growth of the number of college students, the number of idle items on campus has also increased. These items often have certain use value, but due to the lack of effective circulation channels, they are often left idle or even discarded, resulting in waste of resources. This project aims to design and implement a campus idle item sharing platform, providing students with a safe and convenient item rental and trading service.

The platform adopts a front-end and back-end separated architecture. The back-end is based on Node.js and Express.js framework, using MySQL database to store data; the front-end uses uni-app framework, supporting multi-terminal release, including H5 and WeChat mini-program. The main functions of the platform include user management, item release and browsing, order management, message communication and dispute handling modules. The system innovatively introduces a credit score mechanism and dispute handling process, which protects the rights and interests of both parties in the transaction and improves the credibility of the platform.

After testing and verification, the platform can run stably, and all functions can work normally, meeting the actual needs of campus idle item sharing.

**Keywords**: Campus Sharing; Idle Items; Rental Platform; uni-app; Node.js
