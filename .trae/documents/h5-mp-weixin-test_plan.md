# H5和微信小程序适配测试计划

## 现状分析

### 项目配置
- **框架**: UniApp Vue3 + TypeScript
- **H5支持**: ✅ 已配置 (`dev:h5`, `build:h5`)
- **微信小程序支持**: ✅ 已配置 (`dev:mp-weixin`, `build:mp-weixin`)
- **样式**: SCSS + rpx 响应式单位
- **API**: 基于 `@/utils/request.ts` 的统一封装

### 潜在适配问题

| 平台 | 潜在问题 | 风险等级 |
|:---|:---|:---|
| H5 | 路由跳转、滚动行为、样式兼容性 | 中 |
| 微信小程序 | 网络请求域名配置、wx API 兼容性 | 中 |
| 通用 | API 接口调用、数据格式处理 | 低 |

## 测试计划

### 步骤 1: 构建H5版本
- 执行 `npm run build:h5`
- 检查构建是否成功
- 启动开发服务器测试

### 步骤 2: 构建微信小程序版本
- 执行 `npm run build:mp-weixin`
- 检查构建是否成功
- 准备用微信开发者工具测试

### 步骤 3: H5端测试
- 使用浏览器访问H5页面
- 测试页面导航、滚动、API调用
- 检查UI布局和样式

### 步骤 4: API接口测试
- 验证登录、获取物品列表、发送消息等核心API
- 检查接口响应格式和数据处理
