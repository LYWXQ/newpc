# 毕业设计论文写作计划

## 一、项目概述

本项目是一个**校园闲置物品共享平台**，基于 uni-app + Vue 3 + Express + MySQL 技术栈开发，支持物品发布、借用交易、订单管理、纠纷处理等核心功能。

### 项目技术栈
| 分类 | 技术 | 版本 |
|------|------|------|
| 前端框架 | uni-app + Vue 3 | 3.0.0 |
| 构建工具 | Vite | 5.2.8 |
| 后端框架 | Express | 5.2.1 |
| 数据库 | MySQL | 8.0+ |
| ORM | Sequelize | 6.37.8 |
| 状态管理 | Pinia | 2.1.7 |

### 核心功能模块
1. **用户管理**：注册、登录、个人信息管理、信用分系统
2. **物品管理**：发布、浏览、搜索、分类筛选
3. **订单管理**：借用申请、确认、取件码验证、归还、延期申请
4. **消息系统**：站内消息、系统通知
5. **评价系统**：订单评价、信用分关联
6. **纠纷处理**：纠纷申请、举证、管理员裁决
7. **管理员后台**：用户管理、订单管理、纠纷处理
