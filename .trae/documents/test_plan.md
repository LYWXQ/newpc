# 前后端项目测试计划

## 1. 测试目标

### 1.1 功能验证
- 验证前端项目能正常构建和运行
- 验证后端API服务正常响应
- 使用Playwright进行端到端功能测试

### 1.2 ESLint验证
- 检查ESLint配置是否正常工作
- 验证代码规范符合要求

## 2. 测试步骤

### 步骤1: 启动后端服务
- 检查后端依赖
- 启动后端服务器（端口3000）

### 步骤2: 启动前端服务
- 检查前端依赖
- 启动前端开发服务器（端口5173）

### 步骤3: ESLint检查
- 运行npm run lint检查代码规范
- 确保无错误

### 步骤4: Playwright功能测试
- 测试用户注册功能
- 测试用户登录功能
- 测试物品浏览功能
- 测试订单创建功能
- 测试消息功能

## 3. 测试覆盖范围

| 功能模块 | 测试内容 |
|----------|----------|
| 用户认证 | 注册、登录、退出登录 |
| 物品管理 | 浏览物品、搜索物品、查看详情 |
| 订单系统 | 创建订单、查看订单列表、订单详情 |
| 消息系统 | 发送消息、查看消息列表 |
| 个人中心 | 个人信息、收藏、评价 |

## 4. 风险评估

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| 服务启动失败 | 中 | 检查端口占用，确保依赖已安装 |
| 数据库连接失败 | 中 | 确保MySQL服务运行，配置正确 |
| 测试环境问题 | 低 | 使用Playwright的headless模式 |

## 5. 验收标准

- [ ] 后端服务成功启动（端口3000）
- [ ] 前端服务成功启动（端口5173）
- [ ] ESLint检查无错误
- [ ] Playwright测试通过
- [ ] 核心功能正常工作

## 6. 测试命令

```bash
# 启动后端服务
cd backend && npm run dev

# 启动前端服务
cd frontend && npm run dev:h5

# ESLint检查
cd frontend && npm run lint

# Playwright测试
npx playwright test
```
