# 对话功能删除与交易流程完善 - 产品需求文档

## Overview
- **Summary**: 删除点对点聊天功能，仅保留系统消息用于交易进度提醒，完善完整的交易流程（请求→确认→交接→归还）
- **Purpose**: 简化用户交互，聚焦核心交易流程，通过系统消息驱动交易进度
- **Target Users**: 校园闲置共享平台所有用户

## Goals
1. 删除点对点聊天功能，仅保留系统消息
2. 在物品详情页显示发布者的QQ和电话号码供联系
3. 完善交易流程：请求→确认→交接→归还
4. 实现租借物品临期提醒功能
5. 实现信誉分影响机制

## Non-Goals (Out of Scope)
1. 不添加新的社交功能
2. 不修改用户认证流程
3. 不改变现有的物品发布/浏览功能

## Background & Context
当前系统存在点对点聊天功能，但用户反馈对话丢失、体验不佳。为简化流程，决定删除聊天功能，改为直接显示联系方式，同时通过系统消息驱动交易流程。

## Functional Requirements

### FR-1: 删除点对点聊天功能
- 删除前端聊天页面和消息列表页面（保留系统消息）
- 删除后端聊天相关API接口
- 保留系统消息类型用于交易提醒

### FR-2: 显示发布者联系方式
- 在物品详情页显示发布者的QQ和电话号码
- 提供一键复制功能

### FR-3: 交易流程 - 请求阶段
- 买方可以发起交易请求
- 请求包含预计取货时间和地点

### FR-4: 交易流程 - 确认阶段
- 卖方可以确认或拒绝请求
- 卖方确认时可修改时间和地点
- 如时间地点变更，需买方再次确认

### FR-5: 交易流程 - 交接阶段
- 交易确认后进入交接状态
- 生成取件码用于物品交接
- 支持扫码或输入取件码完成交接

### FR-6: 交易流程 - 租借临期提醒
- 租借物品到期前24小时发送提醒
- 提醒双方确认归还时间和地点

### FR-7: 交易流程 - 归还阶段
- 支持确认归还完成
- 支持延期申请（需对方同意）

### FR-8: 信誉分机制
- 按时归还增加信誉分
- 逾期未归还扣除信誉分
- 取消订单影响信誉分

## Non-Functional Requirements
- **NFR-1**: 系统消息推送及时，延迟不超过5秒
- **NFR-2**: 交易状态变更有明确的用户反馈
- **NFR-3**: 支持H5和微信小程序端

## Constraints
- **Technical**: UniApp + Node.js + MySQL
- **Dependencies**: 后端订单系统、消息系统

## Assumptions
1. 用户会在物品详情页查看联系方式并线下沟通
2. 系统消息能及时触达用户
3. 用户会关注系统消息提醒

## Acceptance Criteria

### AC-1: 聊天功能删除
- **Given**: 用户进入消息页面
- **When**: 查看消息列表
- **Then**: 只显示系统消息，无聊天会话列表
- **Verification**: `human-judgment`

### AC-2: 联系方式展示
- **Given**: 用户查看物品详情页
- **When**: 查看发布者信息
- **Then**: 显示QQ号码和电话号码，可一键复制
- **Verification**: `human-judgment`

### AC-3: 发起交易请求
- **Given**: 用户在物品详情页
- **When**: 点击"发起交易"按钮
- **Then**: 弹出表单填写时间和地点，提交后发送请求
- **Verification**: `human-judgment`

### AC-4: 卖方确认请求
- **Given**: 卖方收到交易请求
- **When**: 点击确认或修改时间地点
- **Then**: 若修改，买方收到确认通知；若确认，订单状态变更
- **Verification**: `human-judgment`

### AC-5: 物品交接
- **Given**: 订单已确认
- **When**: 用户输入取件码
- **Then**: 订单状态变为"使用中"
- **Verification**: `human-judgment`

### AC-6: 临期提醒
- **Given**: 租借物品24小时后到期
- **When**: 系统检测到期时间
- **Then**: 向双方发送系统消息提醒
- **Verification**: `human-judgment`

### AC-7: 归还完成
- **Given**: 物品到期或用户申请归还
- **When**: 确认归还
- **Then**: 订单状态变为"已完成"，更新信誉分
- **Verification**: `human-judgment`

### AC-8: 信誉分变更
- **Given**: 订单完成或取消
- **When**: 系统处理订单
- **Then**: 根据规则更新双方信誉分
- **Verification**: `programmatic`
